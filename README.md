# Customer Segmentation and Retail Sales Analysis Using Python

## 1. Project Overview
This project analyzes retail transaction data to understand customer purchasing behaviour, sales performance, and customer value. Python-based analytics techniques are used to identify customer segments, evaluate product revenue, and develop actionable business recommendations.

## 2. Problem Statement
Businesses need to understand which customers generate the most revenue, which customers may become inactive, and which products perform best. This project uses retail transaction data to identify customer behaviour patterns and support data-driven marketing and retention decisions.

## 3. Objectives
- Analyze customer purchasing behaviour and retail sales.
- Clean and prepare transaction data.
- Perform exploratory data analysis (EDA).
- Calculate Recency, Frequency, and Monetary (RFM) metrics.
- Segment customers based on RFM scores.
- Analyze product and country-wise revenue.
- Develop a Strategic Priority Score for customers.
- Provide business recommendations for customer retention and revenue improvement.

## 4. Dataset
The project uses the Online Retail II dataset, which contains retail transaction records. The data includes invoice numbers, product descriptions, quantities, invoice dates, unit prices, customer IDs, and countries.

Dataset source: [Online Retail II on Kaggle](https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci)

## 7. Customer Segmentation Results
The analysis identified the following customer segments:

| Customer Segment | Number of Customers |
|---|---:|
| At Risk | 795 |
| Loyal | 485 |
| High Value | 370 |
| Regular | 338 |
| **Total** | **1,988** |

At Risk was the largest segment, indicating an opportunity to investigate customer inactivity and develop targeted retention campaigns.

## 8. Business Recommendations
- Introduce loyalty rewards for high-value customers.
- Develop re-engagement campaigns for inactive customers.
- Encourage repeat purchases through cross-selling and personalized offers.
- Promote products that contribute strongly to revenue.
- Monitor customer segments and sales trends to guide marketing decisions.

## 9. Conclusion
This project demonstrates how Python and data analysis techniques can be used to understand retail sales, segment customers, and identify opportunities for improved customer retention and revenue growth.
